# Totem POS – Self‑Ordering Platform

Offline‑first, modular POS system for restaurants, food‑service and kiosks.

## Project structure
```
backend/      – Node.js/TypeScript server (Express, WebSocket, CouchDB sync)
mobile/      – Kotlin Multiplatform (Android & iOS client)
kds-web/     – React PWA for Kitchen Display System (TV/Browser)
scripts/     – Helper scripts (setup, lint, test)
docs/        – Architecture, API spec, onboarding
```

## Local development
```bash
# install dependencies (requires Node, Java, Android SDK)
./scripts/setup.sh
# start CouchDB (docker compose)
docker compose up -d couchdb
# run backend
cd backend && npm run dev
# run mobile (KMM) – see mobile/README.md
# run KDS web
cd kds-web && npm run dev
```
